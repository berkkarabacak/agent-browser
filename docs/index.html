Agent Browser

Open many separate browser windows, each with its own accounts and extensions.

⬇ Download for Windows

Windows 10 or 11 · about 12 MB · no administrator password needed

How to install (3 steps)

1Download. Click the blue button above. When the download finishes, open AgentBrowserSetup.exe (it's in your Downloads folder).
2If a blue "Windows protected your PC" box appears: this is normal for new apps. Click More info, then click Run anyway.
3Install. Click Next until it says it's done. An Agent Browser icon appears on your desktop.

The first time you open it

Double-click the Agent Browser icon and click Get started. It downloads the browser it needs, which takes a few minutes, so keep the internet on. After that, click Open on a card to start a browser window and Close to stop it.

How to uninstall

Open Start → Settings → Apps, find Agent Browser, and click Uninstall. It asks whether to keep your profiles; choose No to remove everything.
